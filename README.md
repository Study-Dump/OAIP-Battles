# Сдача

Подготовьте папку `67810X/`, где `X` — номер вашей команды.

```text
67810X/
  solution.cpp
  attacks/
    teamK/
      01_описание/
        input.txt
        expected_output.txt
```

- `solution.cpp`, `input.txt`, `expected_output.txt` — строго с такими именами.
- `teamK/` — атаки против команды `K` (`K != X`). Свою команду не атакуют.
- `01_описание/`, `02_описание/`, … — по папке на тест. Число тестов не ограничено.
- `input.txt` — входные данные (stdin).
- `expected_output.txt` — точный ожидаемый вывод.
- Лишние строки и отладочный вывод ломают тест.
- Если тестов от команды нет, она просто не атакует.
