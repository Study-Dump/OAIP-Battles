# OAIP Battles

## Ввод и вывод

- `input.txt`: первая строка — `N`; если есть параметр, вторая строка — параметр; далее `N` строк записей через `;`.
- `N = 0` — корректный пустой список: `0` (или `0.00` для стоимости).
- `input.txt` может быть пустым или некорректным — тогда `output.txt` пустой.
- Дробные числа — с точкой; в `output.txt` — 2 знака после точки.
- `solution.cpp` читает `input.txt` и пишет `output.txt`; stdin/stdout не использовать.

## Задачи

### Вариант 1. Склад
Поля: `name;article;price;quantity` — название (до 30), артикул (int), цена (double), количество (int).
Сортировка: цена ↑, затем артикул ↑. Вывести общую стоимость и товары.
- Ввод: `N`, затем `N` строк.
- Вывод: стоимость (2 знака), затем `N` строк `name;article;price;quantity`.

### Вариант 2. Расписание
Поля: `destination;flight;hours;minutes;price` — пункт (до 30), рейс (int), часы (int), минуты (int), цена (double).
Выбрать рейсы до пункта; сортировка: время ↑, затем номер рейса ↑.
- Ввод: `N`, пункт, затем `N` строк.
- Вывод: `M`, затем `M` строк `destination;flight;HH:MM;price`.

### Вариант 3. Библиотека
Поля: `author;title;year;pages` — автор (до 40), название (до 40), год (int), страницы (int).
Выбрать книги после года; сортировка: страницы ↑, затем автор и название.
- Ввод: `N`, год, затем `N` строк.
- Вывод: `M`, затем `M` строк `author;title;year;pages`.

### Вариант 4. Успеваемость
Поля: `full_name;group;gpa;missed` — ФИО (до 40), группа (int), средний балл (double), пропуски (int).
Выбрать `gpa > порога`; сортировка: `gpa` ↓, затем ФИО.
- Ввод: `N`, порог, затем `N` строк.
- Вывод: `M`, затем `M` строк `full_name;group;gpa;missed`.

### Вариант 5. Соревнования
Поля: `full_name;age;points;penalty` — ФИО (до 40), возраст (int), очки (double), штраф (int).
Рейтинг: `points - penalty * коэффициент`. Вывести топ-3.
- Ввод: `N`, коэффициент, затем `N` строк.
- Вывод: `M` (до 3), затем `M` строк `full_name;rating`.
- Сортировка: рейтинг ↓, затем очки ↓, затем ФИО.

В вариантах 2–5 `M` — число строк результата; если подходящих записей нет — `0`.

## Сдача

Подготовьте файлы:

```text
solution.cpp
attacks/
  teamK/
    01_описание/
      input.txt
      expected_output.txt
```

- `solution.cpp` — решение своего варианта.
- `attacks/teamK/` — тесты для команды `K` (`K != X`); свою команду не атакуют.
- `01_описание/`, `02_описание/`, … — по папке на тест.
- `input.txt` — ввод; может быть пустым или некорректным.
- `expected_output.txt` — точный вывод; для некорректного ввода — пустой файл.
- Для некорректного ввода решение завершается с кодом `0` и оставляет `output.txt` пустым.
- Нет тестов — команда не атакует.
