# OAIP Battles

Команда `N` решает вариант `N`, ветка `attack-N` — её защита.

## Формат input.txt

- Первая строка — `N`.
- Если в варианте есть параметр, вторая строка — параметр.
- Далее `N` строк записей; поля разделены `;`.
- Строки могут содержать пробелы, но не `;`.
- Дробные числа — с точкой; в `output.txt` — 2 знака после точки.
- `solution.cpp` читает `input.txt` и пишет `output.txt` в рабочем каталоге. stdin/stdout не использовать.
- В `output.txt` только ответ: лишние строки, пустые строки и отладка ломают тест.

## Задачи

### Вариант 1. «Складской учет товаров»

Поля: `name;article;price;quantity` — название (до 30), артикул (int), цена (double), количество (int).

- Вход: `N`, затем `N` строк.
- Выход: первая строка — общая стоимость (2 знака); затем `N` строк `name;article;price;quantity`, по возрастанию цены, при равенстве — по артикулу.

### Вариант 2. «Расписание транспорта / поездов»

Поля: `destination;flight;hours;minutes;price` — пункт (до 30), номер рейса (int), часы и минуты (int), цена (double).

- Вход: `N`, пункт назначения, затем `N` строк.
- Выход: `M`; затем `M` строк `destination;flight;HH:MM;price` для нужного пункта, по возрастанию времени, при равенстве — по номеру рейса.

### Вариант 3. «Электронная библиотека (книжный каталог)»

Поля: `author;title;year;pages` — автор (до 40), название (до 40), год (int), страницы (int).

- Вход: `N`, год, затем `N` строк.
- Выход: `M`; затем `M` строк `author;title;year;pages` для книг после указанного года, по возрастанию страниц, при равенстве — по автору и названию.

### Вариант 4. «Учет успеваемости студентов»

Поля: `full_name;group;gpa;missed` — ФИО (до 40), группа (int), средний балл (double), пропуски (int).

- Вход: `N`, порог, затем `N` строк.
- Выход: `M`; затем `M` строк `full_name;group;gpa;missed` для `gpa > порога`, по убыванию `gpa`, при равенстве — по ФИО.

### Вариант 5. «Каталог участников спортивных соревнований»

Поля: `full_name;age;points;penalty` — ФИО (до 40), возраст (int), очки (double), штраф (int).

- Вход: `N`, коэффициент, затем `N` строк.
- Выход: `M` (до 3); затем `M` строк `full_name;rating`, где `rating = points - penalty * коэффициент`; по убыванию рейтинга, при равенстве — по очкам, затем по ФИО.

В вариантах 2–5 `M` — число строк результата; при отсутствии подходящих записей — `0`.

## Сдача

Подготовьте папку `67810X/`, где `X` — номер вашей группы.

```text
67810X/
  solution.cpp
  attacks/
    teamK/
      01_описание/
        input.txt
        expected_output.txt
```

- `solution.cpp` — решение вашего варианта, строго с таким именем.
- `attacks/teamK/` — ваши тесты для команды `K` (`K != X`). Свою команду не атакуют.
- `01_описание/`, `02_описание/`, … — по папке на тест; число тестов не ограничено.
- `input.txt` — корректный вход для задачи команды `K`.
- `expected_output.txt` — точный `output.txt`, который должна получить задача команды `K`.
- Если тестов от команды нет, она просто не атакует.
